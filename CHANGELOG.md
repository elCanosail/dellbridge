# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
semantic versioning.

## 0.2.0 — unreleased

### Added

- DDC/CI transport over the private `IOAVService` API on Apple Silicon.
- `dellctl` with `list`, `get`, `set`, `input`, `profile` and `packet`.
- Menu bar shell with brightness and input switching.
- Per-model profile loader and the Dell S2725QC profile (unverified).
- M0 hardware check script with read and write probes.
- DMG build, ad-hoc signing, SHA-256 output and one-line installer.
- Homebrew cask template and release automation.

## 0.1.0 — 2026-10-19

### Added

- Initial repository scaffold: Swift package, MCCS packet encoding, tests,
  architecture and roadmap.
